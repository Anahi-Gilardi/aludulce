# 🍓 Alu Dulce — Catering Dulce para Eventos

> **"Hacemos que tus momentos sean únicos"**

Landing page oficial (100% responsive y mobile-first) para **Alu Dulce**, emprendimiento familiar de catering dulce en Argentina.

## ✨ Servicios incluidos
- 🍓 Frutillas bañadas en chocolate (brochettes)
- 🍫 Fuente de chocolate (blanco y negro) con frutas y golosinas
- 🍬 Candy bar / mesa de golosinas
- 🍨 Vasitos de frutillas con crema
- 🎂 Mesas dulces y catering para eventos

## 🛠️ Stack
- **HTML5** semántico + SEO + Schema.org JSON-LD
- **CSS3** vanilla (Mobile-First, variables CSS, animaciones suaves)
- **JavaScript** vanilla (`IntersectionObserver`, Lightbox interactivo, menú mobile y generador de presupuesto hacia WhatsApp)

## 🚀 Cómo abrir o publicar
- **Local:** Abrir `index.html` con doble clic en cualquier navegador.
- **GitHub Pages:** Ir a *Settings → Pages* en este repositorio y seleccionar la rama `main` (`/root`).
